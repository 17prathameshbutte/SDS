# Project Plan

- Create Flask app, config, and environment setup
- Build database schema
- Add login, registration, and role checks

## Stage 2: Student workflow
- Implement complaint submission
- Add file upload support
- Save complaint details in SQLite
- Display student dashboard and ticket list

## Stage 3: Administrator workflow
- Add admin dashboard
- Support search and filters
- Add status update and history tracking

## Stage 4: AI integration
- Add Gemini category and priority suggestions
- Handle failure cases without breaking the complaint workflow

## Stage 5: Validation and documentation
- Run automated tests
- Finish README and design documents
- Add private study guide

## Milestones

1. Project skeleton complete
2. Login and registration working
3. Complaint submission works end-to-end
4. Admin dashboard works
5. AI integration handles missing API keys gracefully
6. Tests pass and documentation is ready
