# Contributing

This project is intended as a learning project and an interview-ready demo. Contributions should stay simple, readable, and beginner-friendly.

## Guidelines

- Keep code understandable for new learners.
- Prefer straightforward Flask and SQLite patterns over advanced abstractions.
- Use meaningful names for variables and functions.
- Add tests when changing core behavior.
- Keep changes focused and small.
- Do not commit secrets or local environment values.

## Local setup

```powershell
cd path\to\your\project-folder
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Checklist

- Update documentation if user-facing behavior changes
- Run the relevant tests before finishing
- Keep app features aligned with the CampusFix problem statement
